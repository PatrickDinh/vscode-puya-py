This repo houses both the Algorand Python and Algorand TypeScript Visual Studio Code language extensions, which provides language server integration and tooling for working with Algorand Python or Algorand TypeScript inside Visual Studio Code.

For details see relevant README file for the [Algorand Python](./packages/python/README.md) or [Algorand TypeScript](./packages/typescript/README.md) language extension.
